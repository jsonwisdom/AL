# CVD Source Gate

Planned implementation files may be mirrored here after they exist in an accessible repository or are supplied as complete source artifacts.

Required before `CVD_CODE_PRESENT = TRUE`:

- complete Rust source;
- `Cargo.toml` and lockfile policy;
- commit SHA binding source to tests;
- reviewable state and recovery enums;
- debounce/hysteresis implementation;
- explicit F005 handling;
- no undocumented kernel-level enforcement claims.
