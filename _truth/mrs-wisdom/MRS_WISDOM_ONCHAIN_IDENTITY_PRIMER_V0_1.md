## Plain English

Jay is building a public proof system.

Instead of saying, "trust me," the system tries to leave receipts:

1. A name or identity surface says who the work belongs to.
2. A file or artifact says what was built.
3. A hash says the exact bytes did not change.
4. A receipt says when and how the work was recorded.
5. A replay shows someone else can check it again.

That is the core idea: protect the family name with records that can be checked.
