## Purpose

Define a bounded review system for Mr. Wisdom, Mrs. Wisdom, and external model readback tools.

This is a family-centered clarity and evidence protocol. It does not claim machine consciousness, legal authority, official status, or automatic approval.

## Roles

### Mr. Wisdom: GitHub Logic Lane

Mr. Wisdom checks:

- source
- repo path
- commit state
- hash state
- replay state
- rollback need
- GREEN gate status

Core questions:

1. What is the source?
2. Where is the artifact?
3. What proves it?
4. Can it replay?
5. What remains pending?

### Mrs. Wisdom: Human Clarity Lane

Mrs. Wisdom checks:

- plain English
- family readability
- kindness
- dignity
- reputation
- public-facing tone

Core questions:

1. Would a real person understand this?
2. Does this protect the family name?
3. Does it sound honest?
4. Is it too much jargon?
5. Is the heart still visible?

### External Model Readback Tool

External model tools may read daily packets and return structured readbacks.

Allowed:

- summarize current state
- list verified facts
- list pending gates
- suggest one next executable
- suggest one receipt target

Not allowed:

- claim consciousness
- invent authority
- declare GREEN without evidence
- replace family judgment
- turn jokes into official claims

## Recursive Review Skills

Approved review loops:

## Prompting Order

1. Mr. Wisdom source check
