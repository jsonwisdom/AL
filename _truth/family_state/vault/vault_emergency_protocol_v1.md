# Vault Emergency Protocol v1

If the family system is stressed:

1. Confirm immediate safety.
2. Identify the current steward.
3. Locate the receipts.
4. Verify hashes before acting.
5. Use the runbook, not panic.
6. Record what changed.
7. Re-verify after recovery.

Failure states:
- Missing steward
- Missing receipt
- Broken hash
- Improvised response above 30 percent
