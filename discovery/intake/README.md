# ALMS Discovery Intake

Purpose:
Capture real field signals during ALMS discovery.

Rule:
No signal = no conclusion.

Valid inputs:
- Discovery Intake Record
- Objection Record
- Governance Question
- Call note
- Email / LinkedIn reply excerpt

Thresholds:
- 0–4 records: intake only
- 5–9 records: preliminary observation
- 10+ records: pattern analysis
- 20+ records: narrative adjustment review
