## Warfare Classes With Jay: Defensive Curriculum

### Class 1: Information Pressure

Learn how narratives move fast and why loud claims need receipts.

```txt
Rule: Reality is what can be checked.
```

### Class 2: Cyber Hygiene

Learn passwords, keys, updates, phishing awareness, and safe sharing.

```txt
Rule: Protect your keys and your future self.
```

### Class 3: Logistics and Systems

Learn how food, fuel, money, data, roads, clouds, and people depend on each other.

```txt
Rule: A system breaks where nobody is looking.
```

### Class 4: Economic Proofs

Learn why machine-speed work needs payment proof, scope, and receipts.

```txt
Rule: No execution without scope.
```

### Class 5: Replay and After-Action Review

Learn how to review what happened without causing more damage.

```txt
Rule: Replay never calls real APIs.
```

### Class 6: Calm Under Noise

Learn how to pause, classify, verify, and refuse panic.

```txt
Rule: Do not let the feed become your commander.
```
