## Homepage Goal

Create a simple, beautiful, kid-safe homepage that lets global learners enter Jay's AL as a learning map.

The page should feel like:

- a classroom
- a game map
- a family compass
- a verifier lab
- a cosmic route through ideas
- a safe doorway into machine-speed learning

## Design Direction

### Visual Feel

- warm off-white background
- soft cosmic map lines
- glowing route nodes
- paper receipt cards
- friendly classroom icons
- playful but not childish
- trustworthy but not sterile

### Typography

- friendly display font for hero
- readable sans for body
- mono font for receipts and JSON blocks

### Color Mood

- warm cream
- soft blue
- gentle green
- gold receipt highlights
- dark ink text
