# DOCTRINE

## Purpose

AL exists to make civic claims verifiable without trust.

We do not publish narratives. We publish machines that produce the same result every time.

## Core Principles

1. **Verify > Narrative**
   - A story is not evidence. A replayable receipt is.

2. **Receipts > Claims**
   - Every public statement must point to a receipt with source, query, and hash.

3. **Replay > Authority**
   - No expert, institution, or model is the source of truth. The replay is.

4. **Sparse-Coverage Honesty**
   - We publish exactly what we have. No interpolation, no filling gaps, no statewide estimates from 4 counties.

5. **Deterministic Verification Posture**
   - Same input + same code = same output, always. No randomness, no hidden state.

## Guardrails

- $0 / BigQuery-only for current NY stack
- No simulated data
- Deterministic receipts with hashes
- Explicit claim boundaries documented in every release
- No attribution or causality claims

## Operational Boundaries

- AL does not create policy recommendations
- AL does not interpolate climate to uncovered counties
- AL does not produce risk atlases
- AL does not assert causality between income and climate
- AL does not accept private, unverifiable data as source

## Public Identity Layer

- Repository: jsonwisdom/AL
- ENS: jaywisdom.base.eth
- Public proof surface serves as the civic interface

This doctrine is constitutional. It does not change per dataset.
