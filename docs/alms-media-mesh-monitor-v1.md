# ALMS Media Mesh Monitor v1

## Doctrine

Reddit finds the smoke. ALMS verifies the fire.

No source is classified as fake until a machine-verifiable contradiction exists. Before that point, external surfaces are treated as escape domains, tiny-source relays, narrative mirrors, archive mirrors, social clips, headline rewrite sites, or syndication copies.

## Core Rule

`NO_SOURCE_IS_TRUTH_UNTIL_RESOLVED_TO_ROOT_AND_CLAIM_MATCHED`

## Scope

- publisher shortlinks
- escape domains
- tiny-source relays
- Reddit-linked sources
- archive mirrors
- social clip sources
- headline rewrite sites
- content syndication copies

## Verdicts

| Verdict | Meaning |
|---|---|
| VALID | Resolves cleanly; publisher identity is traceable; claim matches canonical event. |
| DRIFT | Same event, but materially changed wording, parties, posture, quote, date, or legal state. |
| BREAK | Asserts verdict, liability, or fact not present in primary source or court record. |
| INVALID | Unresolvable, anonymous, spoofed, or screenshot-only with no source trail. |

## Reddit Rule

`REDDIT_IS_DISCOVERY_NOT_PROOF`

Allowed uses:

- surface emerging links
- detect repeated domains
- capture narrative mutation
- identify source clusters

Forbidden uses:

- treat comment consensus as evidence
- treat upvotes as credibility
- treat repost chains as independent confirmation

## Integrity Invariants

1. No premature elevation.
2. No attribution without evidence.
3. No narrative contamination.
4. No screenshot-only proof.
5. No verdict injection.
6. No source becomes truth without root-domain resolution and claim matching.
