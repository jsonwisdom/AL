## I. Purpose

This surface defines how taint, meaning institutional contamination, propagates through the courtroom layer.

Taint is:

- not guilt,
- not falsity,
- not a truth claim,
- not a mechanical verdict,
- not an epistemic judgment.

Taint is institutional caution under constrained admissibility.

It exists to prevent the Courtroom from laundering contamination into admissibility.

## II. Core Doctrine

### 1. Taint Flows Downstream Only

```yaml
taint_flows: downstream_only
```

Taint may propagate:

```text
Provenance -> Replay -> Execution -> Refusal -> Courtroom
```

Taint may never propagate upstream.

This prevents sovereignty recursion.

### 2. Taint Is Not A Truth Claim

```yaml
taint_is_truth_claim: false
```

Taint does not assert:

- correctness,
- falsity,
- reality alignment,
- narrative coherence.

Taint is a classification, not an epistemic act.

### 3. The Courtroom May Propagate Taint

```yaml
courtroom_may_clean_taint: false
```

The Courtroom may:

- acknowledge taint,
- propagate taint,
- classify taint.

The Courtroom may not:

- cleanse taint,
- reinterpret taint,
- downgrade taint,
- override taint.

Only upstream mechanical layers may resolve contamination.

### 4. Taint May Trigger Lawful Termination

```yaml
taint_may_trigger_termination: true
```

If taint intersects with:

- reconstructability,
- sealing integrity,
- jurisdiction,
- standing,
- refusal states,

the Courtroom MUST refuse and terminate without synthetic closure.

This enforces:

```text
Constitutional integrity > institutional continuity
```

### 5. Taint Cannot Be Normalized Or Smoothed

No narrative repair.

No continuity fabrication.

No institutional reinterpretation.

Taint is a hard constraint, not a suggestion.
