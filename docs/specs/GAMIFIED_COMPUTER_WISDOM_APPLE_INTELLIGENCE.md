2. summarize daily missions,
3. remind operator of next action,
4. organize family learning cards,
5. draft plain-language explanations,

Forbidden roles:

1. invent hashes,
2. mark receipts VERIFIED,
3. claim wallet anchoring,
4. override ALMS verdicts,
