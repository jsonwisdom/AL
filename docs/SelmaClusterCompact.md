# Selma Cluster Constitutional Courtesy & Verification Compact

## Purpose
Informational, advisory verification system. No coercive authority.

## Core Principles
- No coercive power
- Advisory labeling
- Due process integration
- Challenge window
- Public record
- Viewpoint neutrality
- Non-sectarian
- Accessibility

## Roles
- Issuer
- Node
- Selma Cluster
- Hearing Council

## Jurisdiction
Evidentiary system only. No legal enforcement authority.

## 9. Soulbound Receipts

9.1 Every finalized claim shall mint a non-transferable ERC-721 receipt token to the issuer.

9.2 Receipt is a permanent public attestation of verification state.

9.3 Receipts are non-transferable and bound to issuer.

9.4 Metadata stored via IPFS tokenURI.

9.5 Receipts may be burned under controlled conditions with audit trail.
