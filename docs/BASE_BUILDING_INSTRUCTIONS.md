# Base + ENS Building Instructions (Human Mode)

## 🧠 The Simple Truth

There are TWO systems:

1. Ethereum (Mainnet) → Identity (ENS)
2. Base (Layer 2)     → Actions (cheap transactions)

---

## 💰 Step 1 — Fund Identity (ENS)

If you are updating ENS records:

👉 You need **MAINNET ETH**

Instruction:

"Hey Jay — send a tiny amount of ETH (like $1–$5) to your main wallet"

Why:
- ENS lives on Ethereum mainnet
- Every update costs ETH gas

---

## ⚡ Step 2 — Fund Action Layer (Base)

If you are publishing or using ALMS:

👉 You need **BASE ETH**

Instruction:

"Hey Jay — send Base ETH to your wallet"

How:
- Bridge ETH → Base
- Or receive Base ETH directly

Why:
- Base is where cheap transactions happen
- EAS (attestations) runs here

---

## 🪪 Step 3 — Understand Identity vs Wallet

You are NOT just a wallet.

You are:

ENS Name: jaywisdom.eth (identity)
↓
Resolves to wallet
↓
Wallet signs transactions

---

## 🔐 Step 4 — Two Wallet Roles (Important)

1. Identity Wallet (ENS owner)
   - Controls ENS
   - Uses MAINNET ETH

2. Publisher Wallet (Base)
   - Sends transactions
   - Uses BASE ETH

These can be the SAME wallet or DIFFERENT.

---

## 🧾 Step 5 — Simple Mental Model

If it says:

- ENS → use ETH
- Base / cheap → use Base ETH

---

## ⚠️ Common Mistakes

❌ Sending ETH when Base is needed  
❌ Sending Base ETH when ENS is needed  
❌ Assuming ENS works on Base  

---

"ETH = identity"
