## 1. Purpose

Define valid observer state movement as a mechanical table.

## 2. State Set

```text
OBSERVER_IDLE
OBSERVER_INPUT_RECEIVED
OBSERVER_DESCRIPTOR_VALID
OBSERVER_RECORDING
OBSERVER_HASHED
OBSERVER_CHAINED
OBSERVER_REPLAY_READY
OBSERVER_BLOCKED
```

## 3. Event Set

```text
SUBMIT_DESCRIPTOR
VALIDATE_DESCRIPTOR
RECORD_OBSERVATION
COMPUTE_HASH
VERIFY_PREV_HASH
MARK_REPLAY_READY
BLOCK_FORBIDDEN_SURFACE
RESET_WITH_NEW_INPUT
```

## 4. Transition Table

```text
OBSERVER_IDLE + SUBMIT_DESCRIPTOR -> OBSERVER_INPUT_RECEIVED
OBSERVER_INPUT_RECEIVED + VALIDATE_DESCRIPTOR -> OBSERVER_DESCRIPTOR_VALID
OBSERVER_DESCRIPTOR_VALID + RECORD_OBSERVATION -> OBSERVER_RECORDING
OBSERVER_RECORDING + COMPUTE_HASH -> OBSERVER_HASHED
OBSERVER_HASHED + VERIFY_PREV_HASH -> OBSERVER_CHAINED
OBSERVER_CHAINED + MARK_REPLAY_READY -> OBSERVER_REPLAY_READY
ANY + BLOCK_FORBIDDEN_SURFACE -> OBSERVER_BLOCKED
OBSERVER_BLOCKED + RESET_WITH_NEW_INPUT -> OBSERVER_IDLE
```
