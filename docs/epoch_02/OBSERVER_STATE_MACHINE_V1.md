# OBSERVER_STATE_MACHINE_V1

## Status

```text
EPOCH_02_COMPONENT = OBSERVER_STATE_MACHINE_V1
SCOPE              = JURISDICTION_EXTENSION_ONLY
AUTHORITY          = FALSE
ATTESTATION        = DORMANT
MEMBRANE           = INTACT
NO_FAKE_GREEN      = ACTIVE
```

## 1. Purpose

Define the minimal mechanical state transitions for jurisdiction observers.

The state machine records observer movement only. It does not interpret targets, issue attestations, rank risk, or grant authority.

## 2. States

```text
OBSERVER_IDLE
OBSERVER_INPUT_RECEIVED
OBSERVER_RECORDING
OBSERVER_REPLAY_READY
OBSERVER_BLOCKED
```

## 3. Events

```text
EVENT_SUBMIT_DESCRIPTOR
EVENT_VALIDATE_DESCRIPTOR
EVENT_RECORD_OBSERVATION
EVENT_COMPUTE_RECEIPT_HASH
EVENT_VERIFY_REPLAY_SURFACE
EVENT_BLOCK_FORBIDDEN_SURFACE
EVENT_RESET_WITH_NEW_INPUT
```

## 4. Transition Table

```text
OBSERVER_IDLE + EVENT_SUBMIT_DESCRIPTOR -> OBSERVER_INPUT_RECEIVED
OBSERVER_INPUT_RECEIVED + EVENT_VALIDATE_DESCRIPTOR -> OBSERVER_RECORDING
OBSERVER_RECORDING + EVENT_COMPUTE_RECEIPT_HASH -> OBSERVER_REPLAY_READY
ANY + EVENT_BLOCK_FORBIDDEN_SURFACE -> OBSERVER_BLOCKED
OBSERVER_BLOCKED + EVENT_RESET_WITH_NEW_INPUT -> OBSERVER_IDLE
```

## 7. Non-Effects

This state machine may not:

```text

RANK_RISK
ISSUE_ATTESTATION
GRANT_AUTHORITY
PROMOTE_GREEN
MUTATE_EPOCH_01
```
