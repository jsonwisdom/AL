## What This Means

25/8 is not a literal work requirement.

It means the learning system is always ready to receive, classify, verify, replay, and receipt new public learning inputs.

Alabama Governance Flywheel is a game/simulator for learning how rules, proposals, budgets, agencies, schools, families, and public systems can become more checkable.

It does not claim legal authority, government power, election authority, court power, or official state status.
