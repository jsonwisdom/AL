## LAW Layers

### L: Learning

Learning means every person can start from zero and understand the rule.

```txt

```

### A: Accountability

Accountability means every important action produces a checkable trail.

```txt
If it matters, keep the receipt.
```

### W: Wisdom

Wisdom means using speed without causing harm.

```txt
Fast is not enough. It must be safe, scoped, and checkable.
```
