It may discuss public institutions, public officials, public documents, public claims, and public processes as public-output review surfaces.

## Daily Loop

```txt
Start from Zero.
Pick one public signal.
Classify the signal.
Find or request the source.
Protect private data.
Extract dates, claims, amounts, and actors.
Separate fact, claim, opinion, satire, and unknown.
Create a receipt.
Explain in plain language.
Add comedy only after labeling it as comedy.
Return with next lawful question.
Repeat tomorrow.
```
