## Root Name

The Alabama Looking Glass Project.

This is Jay's environment for looking at public systems clearly, turning confusing signals into checkable artifacts, and routing learning through receipts, replay, and applied wisdom.

This is not a retreat from ambition.
This is the naming of the room.

## What It Is

The Alabama Looking Glass Project is a public-scale learning and verification framework for:

- citizen letters
- public documents
- local media signals
- school learning
- family wisdom
- governance claims
- timeline drift
- process flaws
- receipt-backed explanations
- replayable public learning

## Core Loop

```txt
Receive signal.
Redact private data.
Classify input.
Extract dates and claims.
Attach source.
Hash evidence.
Create receipt.
Monitor time drift.
Replay if disputed.
Teach the pattern.
Propose lawful fix.
Repeat.
```
