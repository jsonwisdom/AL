## Purpose

Applied Wisdom turns Jay's AL from a map of ideas into a daily life path.

The goal is not to tell people who to be.

The goal is to help learners choose one better move each day, check reality, protect privacy, build useful skills, and keep receipts of growth.

## Root Rule

```txt
Every day is one move.
Make it checkable.
```

## Daily Practice

```txt
1. What am I seeing?
2. What do I need to protect?
3. What can I check?
4. What can I improve?
5. What did I learn?
```

## Student Translation

```txt
See clearly.
Stay safe.
Check first.
Build small.
Remember what worked.
```

## Parent Translation

```txt
Help the child choose one safe mission, check one thing, protect one private detail, and celebrate one receipt of learning.
```

## Teacher Translation

```txt
Turn classwork into checkable moves: source, rule, action, evidence, reflection.
```

## Builder Translation

```txt
Every product feature must map to a safe life skill: checking, privacy, receipts, replay, scope, or reflection.
```
