## Game Objective

Players learn how to move through a fast world without getting fooled, exposed, unpaid, or ungrounded.

They win by turning confusion into checkable learning.

## Core Game Loop

```txt
Start from Zero.
Pick a mission.
Read the rule.
Check the source.
Protect privacy.
Define scope.
Run the verifier.
Replay if needed.
Keep the receipt.
Make the wise next move.
```
