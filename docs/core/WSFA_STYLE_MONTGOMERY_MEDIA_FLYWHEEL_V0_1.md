## Root Idea

That sounds like a WSFA media flywheel straight out of Montgomery.

But this is not WSFA.
This is not a newsroom claim.
This is not media impersonation.

This is a local-media-style learning flywheel for turning public information into checkable receipts.

## Plain Version

```txt
Local news finds what happened.
Jay's AL teaches how to check it, receipt it, and learn from it.
```

## Flywheel Loop

```txt
Watch public signal.
Capture source.
Classify claim.
Check context.
Hash evidence.
Create receipt.
Explain plainly.
Replay if disputed.
Publish learning output.
Repeat.
```

## Montgomery Lens

Montgomery is treated as a learning context:

- local public information
- civic education
- school learning
- family learning
- public documents
- community events
- institutional announcements
- media literacy

It is not treated as a jurisdictional command surface.
