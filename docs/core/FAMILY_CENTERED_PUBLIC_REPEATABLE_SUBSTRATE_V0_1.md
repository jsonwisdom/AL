## Public Repeatable Rule

No private family details are required for the public to learn the system.

The public receives:

- rules
- routes
- examples
- receipts
- replay paths
- safe games
- classroom language
- verifier logic

The public does not receive:

- private addresses
- private child data
- family secrets
- personal surveillance
- coercive identity roles
