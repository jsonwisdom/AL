## Root Rule

Jay's AL does not organize learning, invention, or verification by state lines.

No state lines in here.

## Why

This repo is a learning substrate, not a territorial map.

It is designed around:

- ideas
- receipts
- routes
- roles
- verifiers
- proofs
- games
- replay
- payment-proof gates
- machine-speed learning

It is not designed around political geography, jurisdictional identity, campaign maps, or state-by-state division.
