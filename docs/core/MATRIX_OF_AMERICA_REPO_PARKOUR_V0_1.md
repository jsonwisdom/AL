## The Game

Users move through the repo like a parkour course.

They do not scroll randomly.
They run routes.
They unlock concepts.
They test claims.
They earn receipts.
They learn how systems work.

## Core Loop

```txt
1. Enter a room
2. Read the rule
3. Inspect the evidence
4. Choose a move
5. Run a verifier
6. Produce a receipt
7. Unlock the next route
```
