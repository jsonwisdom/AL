# Jay's Substrates Ground Rules v0.1

Status: Draft Core Ground Rules  
Builder: jaywisdom.base.eth  
Scope: AL, Receiptd, Atomic JSONWisdom, public verifier economy  
Authority: false

## Why

Jay starts from Zero every day because recursive social systems, political feeds, economic claims, and machine-speed narratives can erase context faster than humans can stabilize it.

The answer is not panic, prophecy, or retaliation.

The answer is substrate discipline.

Every claim, payment, fix, dispute, and learning event must pass through bounded proof surfaces before it can become part of Jay's build.

```json
{
  "root_principle": "START_FROM_ZERO_WITH_RECEIPTS",
  "meaning": "No claim receives status until it survives evidence, scope, payment proof, replay, or refusal gates.",
  "authority": false

```

## Substrate 1: Claim Substrate

All claims enter as untrusted inputs.

A claim may be:

- factual
- predictive
- interpretive
- economic
- legal
- civic
- social
- adversarial
- satire
- unknown

Ground rule:

```json
{
  "claim_default_status": "UNVERIFIED",
  "promotion_requires": [
    "source",
    "timestamp",
    "evidence_classification",
    "scope_boundary",
    "receipt_or_refusal"
  ]
}
```

No feed, official, personality, institution, model, or crowd receives automatic truth status.

## Substrate 2: Payment-Proof Substrate

Machine-speed help requires machine-speed payment clarity.

Ground rule:

```json
{
  "law": "PAYMENT_PROOF_GATES_EXECUTION",
  "fix_execution_without_payment_proof": "FAIL_CLOSED",
  "payment_units": "minor_units_only",
  "float_money": false
}
```

No unpaid execution loop may consume worker, agent, verifier, or infrastructure capacity without explicit scope and payment proof.

## Substrate 3: Scope Substrate

Every action must have a boundary.

Ground rule:

```json
{
  "every_fix_requires": [
    "scope_hash",
    "task_description_hash",
    "allowed_actions",
    "forbidden_actions",
    "expiry_or_sla"
  ],
  "scope_expansion_without_new_receipt": "FORBIDDEN"
}
```

A paid task does not authorize adjacent tasks. A replay target does not authorize live APIs. A civic learning demo does not authorize real-world adjudication.

## Substrate 4: Replay Substrate

Replay is the truth machine.

Ground rule:

```json
{
  "replay_never_calls_real_apis": true,
  "replay_inputs": "recorded_fixtures_only",
  "divergence_detection": "hash_comparison",
  "verdict_requires_signature": true
}
```

Replay proves whether a bounded execution matched the receipt. Replay does not become surveillance, retaliation, or live mutation.

