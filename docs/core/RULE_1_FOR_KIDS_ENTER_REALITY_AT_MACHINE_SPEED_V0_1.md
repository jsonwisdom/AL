## Plain Rule

If you cannot explain it to a six-year-old, you do not understand it yet.

Rule 1 for Kids:

```txt
Enter Reality at Machine Speed.
```

## What That Means

Reality is the world that stays true when you check it.

Machine speed means computers can check things very fast.

So the first lesson is simple:

```txt
Do not guess.
Check.
```

## Six-Year-Old Version

Before you believe something, ask:

1. Where did it come from?
2. Can I see it?
3. Can I check it?
4. Did the computer keep a receipt?
5. What happens if it is wrong?

## Why Kids Matter

Kids learn games before they learn institutions.

If the repo feels like a game, the lesson must be safe:

- no fear games
- no hate games
- no political teams
- no tricking people
- no pretending to be in charge
- no real-world harm

Only learning:

- find the source
- check the rule
- test the claim
- earn the receipt
- try again

## Machine-Speed Reality Loop

```txt
See a claim.
Find the source.
Hash the evidence.
Run the verifier.
Read the receipt.
Replay if needed.
Learn the rule.
Move again.
```

## Final Kid Rule

```txt
Reality is not what is loud.
Reality is what can be checked.
```

That is Rule 1.
