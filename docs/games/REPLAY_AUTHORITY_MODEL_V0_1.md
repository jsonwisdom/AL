## 1. AUTHORITY COMPUTATION

Authority is computed as a weighted function of:

- reputation (falsification cost)
- challenge survival
- settlement correctness
- governance participation
- epoch continuity contributions
- supersession correctness
- environment stability

Formally:

```text
authority_score = f(
    reputation_vector,
    challenge_survival_rate,
    settlement_correctness,
    governance_integrity,
    epoch_continuity,
    supersession_validity,
    environment_stability
)
```

Authority is earned, not granted.
