## Purpose

Meme Metaverse is a public utility for local speech at county resolution.

It is not a map of stereotypes. It is a receipt-aware cultural layer where local phrases, context, corrections, and attestations can be recorded without pretending that language is frozen.

## Daily Docker Dockets

Daily Docker Dockets are the daily public record lane for Meme Metaverse updates.

Each docket should be small, verifiable, and replayable.

A docket may include:

- county FIPS code
- county and state
- phrase or local expression
- IPA or pronunciation note
- context of use
- first sighting or date observed
- source note
- attestor identity
- attestation UID, if anchored
- correction or revocation note, if applicable

## Rules

1. A county entry is not final because it sounds right.
2. A phrase is admissible only when the source, context, and seam are named.
3. Attestations strengthen the public record but do not erase future corrections.
4. Revocation is not shame. It is visible maintenance.
5. ENS is discovery. EAS is witness. GitHub is public replay surface.
