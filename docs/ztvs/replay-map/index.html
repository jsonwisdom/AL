1 · Core Problem
Green Dashboard Fallacy

Kill the Green Dashboard fallacy.

A dashboard saying “green” is not proof.

Only receipts, hashes, replay, quorum, and witnesses can prove state.

2 · Core Rule
Presentation vs Authority

UI is presentation.
Receipts are authority.
Replay is proof.

  • No fake green.
  • No silent mutation.
  • No admin override.
3 · Architecture
Layered Proof Stack
  • Inside Layer
    Official sources are captured as raw evidence.
  • Middle Layer
    Replay engine verifies receipts and hashes.
  • Outside Layer
    Dashboard only reads from verified/latest.json.
4 · Registry
Root of Trust

The Registry defines:

  • What sources count
  • What hashes are valid
  • What quorum is required
  • What receipts are accepted

Registry changes must be treated like constitutional amendments.

5 · Governance Protocol
Amendment Flow

Registry updates require:

  • Proposal
  • Gauntlet simulation
  • 4/5 quorum
  • Witness receipts
  • Constitutional Pause
  • Replay preservation check
  • Epoch activation
6 · Receipt Classes
Canonical Evidence

Three receipt classes:

  • REGISTRY_RELEASE_V0_1
  • CONSTITUTIONAL_PAUSE_V0_1
  • SYSTEM_VETO_RECEIPT_V0_1

All must use:

  • version: "0.1"
  • replay_preservation_status: "TRUE" | "FALSE"
  • sha256 anchors only
  • additionalProperties: false
  • RFC8785_JCS canonicalization
7 · Epoch Transition
No Verification Gap

Epoch rule: Sₙ remains active until Sₙ₊₁ proves itself.

No verification gap.

Happy path:

  • Pause passed
  • No veto receipts
  • Pause window closed
  • Replay preservation TRUE
  • Activate Sₙ₊₁
  • Deactivate Sₙ

Veto path:

  • Replay preservation fails
  • Emit SYSTEM_VETO_RECEIPT_V0_1
  • Keep Sₙ active
  • Abort transition
Final Lock
Law of the System

Old law governs until new law proves itself.
