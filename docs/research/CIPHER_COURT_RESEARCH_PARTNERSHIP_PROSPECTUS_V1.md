## One-Line Summary

Cipher Court is an open telemetry instrument and playable calibration intervention for measuring whether adaptive adversarial evidence reduces overconfidence under deception.

## Core Study

```text
N = 200 participants
PRE_TEST = standardized scam / phishing susceptibility battery
INTERVENTION = 10 hours Cipher Court training
POST_TEST = standardized scam / phishing susceptibility battery
GROUPS = adaptive Noise Agent vs fixed-difficulty Noise Agent
```

## Open Science Commitment

The measurement layer is open.

```text
REPLICATION_OVER_PROPRIETARY_ORACLE
```

The telemetry schema is designed so independent labs can replicate, challenge, and pool results without requiring access to proprietary game internals.

## Data Boundary

Telemetry measures behavior, not identity.

Required principles:

```text
MINIMIZE_PERSONAL_DATA
ALLOW_OPT_OUT
PUBLISH_AGGREGATE_RESULTS
SEPARATE_GAME_TELEMETRY_FROM IDENTITY
```

No unnecessary personal identifiers are required for the core instrument.

## Replay Sovereignty Guarantee

Cipher Court never allows confidence, persuasion, role consensus, or telemetry trends to override deterministic replay.

```text
CONFIDENCE != VERDICT
REPLAY_PASS = VERDICT
TELEMETRY_MUST_NOT_OVERRIDE_REPLAY
```
