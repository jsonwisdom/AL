## Premise

Classic *WarGames* (1983) asked:

**Can the machine decide?**

This game asks the sharper 2026 question:

**Can the machine prove what it saw, what it did, who allowed it, and whether a human reviewed it?**

No missiles.  
No exploits.  
No operational guidance.  

This is a civic verification game about evidence chains, replayability, and preserved human authority.
