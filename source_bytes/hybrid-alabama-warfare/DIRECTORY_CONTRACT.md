# Hybrid Alabama Warfare — Source Bytes Directory Contract v0.1

Authority created: `false`

Admitted:
- exact public-source byte captures
- SHA-256 digests
- byte length
- requested/resolved URL
- observed timestamp
- media type
- provenance metadata

Forbidden:
- deriving scope or legal authority from filenames or URL wording
- treating an official-looking page as self-authenticating beyond the captured source
- treating identical SHA values from distinct URLs as the same source identity without an explicit binding

Core law:
`BYTES_PROVEN != SCOPE_PROVEN != AUTHORITY_PROVEN != CLAIM_TRUE`
