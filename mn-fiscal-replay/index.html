How verification works

Source manifestStored pointer, hashes, and source metadata.
Live fetchA later copy of the same source is retrieved.
Text normalizationExtracted text is normalized for comparison.
Paragraph comparisonDocument text is compared in small chunks.
Review classificationDetected differences are reviewed before public claims.
CertificateA final receipt records the public status.

Why formatting drift is not automatically a discrepancy

PDF files often produce different extracted text when page numbers, table-of-contents spacing, footnotes, line breaks, or layout metadata shift. This project treats those differences as formatting or extraction artifacts unless the actual fiscal figures, tables, or sentences are proven to have changed.

No public discrepancy claim has been issued. Current reviewed evidence supports baseline maintenance only: formatting drift was detected, reviewed, and classified as non-substantive.
