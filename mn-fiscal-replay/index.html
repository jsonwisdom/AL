What this is

A Librarian-first audit trail

This project turns raw source files, manifests, replay receipts, live fetches, chunk diffs, human classifications, and final safe-status receipts into a public lineage index. The point is simple: nobody should have to hunt through raw files to find the evidence.

  • Librarian: discovers existing lineage before asking a human for anything.
  • Boss Bre: blocks public claims unless the receipts prove them.
  • Safe Baseline: allows maintenance when drift is extractor/layout noise, not proven content change.

Doctrine
