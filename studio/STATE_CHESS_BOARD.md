# The State Chess Board

## What It Is
A live, verifiable map of every policy claim a state makes — matched or
mismatched against ground truth at machine speed.

## How It Works

1. **State issues a claim** → Registered on-chain
2. **Three classes of nodes verify** → Government, Infrastructure, Civilian
3. **Selma Bridge computes consensus** → Match, Mismatch, or Contested
4. **Soulbound receipt minted** → Permanent proof artifact
5. **Dashboard updates** → Public, real-time, tamper-evident

## Why It Matters

- **For Governors:** Real-time accountability dashboard
- **For Citizens:** Proof that claims match reality
- **For Journalists:** Immutable match/mismatch logs
- **For History:** Permanent receipt artifacts

**Build the board. Teach the board. Prove the board. Monetize the artifacts.**
