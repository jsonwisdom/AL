## Why `studio/`?

This directory is the commercialization and publishing layer of the Alabama
Machine Speed Proof system. It contains no deployable protocol code — that
lives in `contracts/`. What lives here: narrative engines, learning modules,
visual assets, business models, and the product catalog.

**`studio/` = content, packaging, design, training, and monetization.**

---

## Core Thesis

Every move on the state chess board produces a reusable artifact — legal,
educational, technical, visual, or civic. These artifacts become the revenue
layer, trust layer, and learning layer simultaneously.
